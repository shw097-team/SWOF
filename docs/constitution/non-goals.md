# Non-goals (W0 boundary)

Explicit from the construction order and PI-PKG-00 §1.4:

- No second RBWI, second compiler, second orchestrator, second task DB, second semantic root or
  parallel canonical writer.
- No mutation of the source corpus, HG-KSEOS source/config, or Fabric canonical contracts.
- No provider/tool becomes semantic authority; runtime state stays replaceable.
- No external acceptance, release, production or unqualified world-effect claim from this root.
- W1–W5 are `PLANNED_NOT_DISPATCHED`; nothing beyond W0 is implemented here.
